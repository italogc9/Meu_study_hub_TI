
# Meu Study Hub - Tecnologia da Informação

## Sobre o projeto

Este repositório foi criado para organizar meus estudos, atividades acadêmicas e projetos desenvolvidos durante a graduação em Ciência da Computação.

O objetivo é registrar minha evolução, facilitar o acesso aos materiais e construir meu portfólio na área de tecnologia.

## Organização

- **02_Disciplinas_Atuais:** atividades, anotações e materiais das disciplinas da faculdade.
- **03_Projetos_e_Certificados:** projetos pessoais, trabalhos práticos e certificados.
